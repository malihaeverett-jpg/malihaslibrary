THE CRUEL PRINCE PAGE — ADD WITHOUT REPLACING YOUR EXISTING FILES

1. Extract this ZIP.
2. Copy cruel-prince.html, cruel-prince.css, cruel-prince.js and the whole cruel-prince-images folder into the same Website Project folder as index.html.
3. In index.html, find the existing Cruel Prince card link:
   href="book.html?book=cruel-prince"
   Change only that link to:
   href="cruel-prince.html"
   This one small link change is necessary so the Cruel Prince card opens its own page. Do not change the other cards or replace your existing CSS/JS.
4. Save and click the Cruel Prince card. The Back to the Library links return to index.html; if your homepage filename differs, update those links in cruel-prince.html.
5. The images folder is named cruel-prince-images to avoid overwriting the images used by the Alchemised page.
