SCYTHE PAGE — ADD AS A SEPARATE PAGE

1. Extract this ZIP.
2. Copy scythe.html, scythe.css, scythe.js and the entire scythe-images folder into the same Website Project folder as index.html.
3. In index.html, find the Scythe card link:
   href="book.html?book=scythe"
   Change only that href to:
   href="scythe.html"
   Leave the Alchemised and The Cruel Prince links unchanged.
4. Save all files and click the Scythe card.
5. Keep scythe-images beside scythe.html. Image names are citra.jpg, rowan.jpg, and scythe-symbol.jpg.
6. If your homepage filename is different from index.html, update the return links in scythe.html.
